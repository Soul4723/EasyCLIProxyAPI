## 修復

- 本次重新發布包含日誌資料夾修復的版本，補齊 v0.3.48 首批發布套件中遺漏的修復。若使用 v0.3.48 仍出現此錯誤，請升級至本版本並重新啟動應用程式。
- 修復在進階功能中開啟日誌資料夾時出現堆疊溢位錯誤（`Maximum call stack size exceeded`）的問題。
- 針對 Linux 上滑鼠移入後部分內容變成白畫面或透明的重繪問題，恢復主視窗的不透明模式，涵蓋 AMD / KDE 與 NVIDIA / Hyprland 等回報情境。Windows 與 macOS 的原生半透明主題支援不受影響。[#491](https://github.com/router-for-me/EasyCLIProxyAPI/issues/491)

## 改善

- 改善背景資源使用：背景啟動、最小化或縮至系統匣時，同步主介面與外掛 WebView 的可見性，暫停介面輪詢與倒數計時；還原視窗後自動重新整理最新資料。代理核心與用量收集持續運作。[#493](https://github.com/router-for-me/EasyCLIProxyAPI/issues/493)
- 用量頁改為合併事件更新，備用輪詢由每秒一次調整為每 10 秒一次；視窗隱藏時停止向介面傳送用量更新事件，減少背景查詢與繪製負擔。
- 恢復瀏覽器預設的背景節流策略。介面更新依原生視窗是否顯示及是否最小化判斷，不會僅因失去焦點而暫停。
- 將 Tauri 升級至 2.12.4 穩定版，並同步更新相關執行階段與建置相依套件。

## 部分歷史更新

### 新增

- Codex「設定管理」新增**自動審批模型**設定，可選擇 Codex 預設或指定模型；儲存後同步至模型目錄，新發現的模型自動繼承設定。所選模型須能透過目前的代理呼叫。
- Codex 新增**遠端壓縮（實驗性）**開關，預設關閉，可在上游支援時啟用伺服器端上下文壓縮。
- Codex 支援切換為 `openai` 提供商識別，仍透過 CPA 代理；切換時可選擇備份並同步本機歷史對話。

### 改善

- 額度卡片支援依模型分組顯示不同時間範圍的額度，新增重設倒數計時，調整方案資訊與重新整理按鈕配置。
- 應用程式重新啟動後可還原上次的視窗位置。
- 外掛安裝過程中支援透過取消、關閉按鈕或 Esc 中止安裝請求。

### 修復

- 修復用量費用計算可能優先使用手動價格的問題，現在優先比對實際原始模型的自動價格，再使用備用價格。
- 修復啟用費用欄後，推理 Token 數量遭到擠壓、無法完整顯示的問題。
- 修復設定頁面中輸入框擠壓設定名稱與說明文字的問題。
- 修復 macOS 下 DeepSeek Harness 桌面應用程式及其內建 CLI 的識別問題。

### 使用提示

- 修改 Codex 設定後，請重新啟動對應的 CLI 服務或桌面應用程式。遠端壓縮開關會變更提供商名稱；若歷史對話不再顯示，可前往「對話管理」重新同步。
