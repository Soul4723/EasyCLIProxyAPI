## 改善

- CPA 経由で ZCode に接続するモデルは、既定で画像入力を有効にします。`inputFormat.supportsImage: true` を自動生成し、画像対応のメタデータがないモデルも対象にします。既存の手動設定は保持されます。
- 新規インストール時、または明示的な設定がない場合、プラグインを既定で有効にします。明示的に無効化された設定は保持されます。
- README のアプリ画面のスクリーンショットを更新し、現在のインターフェースとクライアント設定画面を掲載しました。

## ご利用上の注意

- 更新後は ZCode の設定を再適用し、ZCode を再起動して既定の画像入力設定を有効にしてください。
- 画像入力の設定はクライアントからの画像送信を許可します。実際の画像認識への対応は、選択したモデルと上流サービスに依存します。

## 修正
