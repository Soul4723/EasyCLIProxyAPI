## 改善

- ウィンドウ幅が 901〜1100px のとき、サイドバーはツールチップ付きのアイコン表示に切り替わり、ページのツールバーやタブが切れなくなりました。
- 認証ファイルカードの「最近のリクエスト」タイムラインに、生のタイムスタンプではなくローカル時刻の範囲（例: `14:10-17:30`）を表示します。
- 認証ファイルカードの操作ボタンを揃え、削除ボタンを危険操作のスタイルにしました。一括削除の確認ダイアログのタイトルを「N 件のファイルを削除しますか？」とし、確認ボタンを目立つ赤色にしました。
- ホームのコア状態をわかりやすくしました。状態を取得できない場合はその旨と「再試行」ボタンを表示し、エラー詳細は展開して確認できます。コア未インストール時は「コアをインストール」ボタンからバージョン管理へ直接移動できます。読み込み中にカードが跳ねなくなりました。
- ブラウザの検出中、OAuth サインインボタンに読み込み表示とヒントを表示します。
- Codex サブエージェント設定ダイアログに読み込み状態と「再試行」付きのエラー表示を追加し、長いタイトルは折り返します。
- 使用状況の分析で、成功率ドーナツグラフの注記が数値に重ならず、時間軸ラベルも重ならなくなりました。リクエスト詳細の範囲表示もより正確になりました。
- ビギナーモードで選択中のソースカードがよりわかりやすくなりました。
- プラグインと設定の検索欄を広げました。データ管理のサイズ入力欄に枠線、フォーカス表示、入力例を追加し、ダークテーマでも見やすくしました。

## 修正

- 「1 models」などの単数・複数形の誤りを修正しました。
- 繁体字中国語の画面で一部が簡体字で表示される問題を修正しました。
