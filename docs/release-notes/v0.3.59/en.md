## Improved

- Between 901px and 1100px wide, the sidebar collapses to an icon rail with tooltips, so page toolbars and tabs are no longer cut off.
- The "Recent requests" timeline on authentication file cards now shows local time ranges (for example `14:10-17:30`) instead of raw timestamps.
- Authentication file card actions are aligned and Delete uses a danger style. The batch delete confirmation is now titled "Delete N files?" with a solid red confirm button.
- Clearer core status on Home: when the status can't be read, it says so and offers Retry, with the error in an expandable details section. Without an installed core, an "Install core" button goes straight to Version Management. The card no longer jumps while loading.
- OAuth sign-in buttons show a spinner and a tooltip while browsers are being detected.
- The Codex subagent settings dialog shows a loading state and a load error with Retry, and long titles wrap.
- In Usage analysis, the success-rate donut note no longer overlaps the value, time-axis labels no longer collide, and the request details range text is more accurate.
- The selected source card in Beginner Mode stands out more clearly.
- Wider plugin and settings search fields. The Data Management size fields have a visible frame, focus state, and example placeholder, including in dark themes.
