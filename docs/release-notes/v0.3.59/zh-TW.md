## 改善

- 視窗寬度在 901–1100px 之間時，側邊欄自動收合為圖示列並顯示提示，頁面工具列與分頁不再被截斷。
- 認證檔案卡片的「最近請求」時間軸改為顯示本地時間區段（如 `14:10-17:30`），不再顯示原始時間戳記。
- 認證檔案卡片的操作按鈕對齊，刪除按鈕使用危險操作樣式；批量刪除的確認對話框標題改為「刪除 N 個檔案？」，確認按鈕改為醒目的紅色。
- 首頁核心狀態更清楚：讀取失敗時顯示「無法讀取核心狀態」與「重試」按鈕，錯誤詳細資訊可展開查看；未安裝核心時提供「安裝核心」按鈕，直接前往版本管理；載入時卡片不再跳動。
- OAuth 登入按鈕在偵測瀏覽器期間顯示載入動畫與提示。
- Codex 子代理設定對話框新增載入狀態與附「重試」的載入失敗提示，長標題自動換行。
- 用量分析的成功率環形圖說明文字不再與數值重疊，時間軸標籤不再擠在一起，請求明細的範圍說明更準確。
- 新手模式中選取的來源卡片更加醒目。
- 外掛與設定搜尋框加寬；資料管理的大小輸入框增加邊框、焦點狀態與範例提示文字，深色主題下也清楚可見。
