## 优化

- 窗口宽度在 901–1100px 之间时，侧边栏自动收起为图标栏并显示悬停提示，页面工具栏和标签页不再被截断。
- 认证文件卡片的“最近请求”时间轴改为显示本地时间段（如 `14:10-17:30`），不再显示原始时间戳。
- 认证文件卡片的操作按钮对齐，删除按钮使用危险操作样式；批量删除的确认对话框标题改为“删除 N 个文件？”，确认按钮改为醒目的红色。
- 首页核心状态更清晰：读取失败时显示“无法读取核心状态”和“重试”按钮，错误详情可展开查看；未安装核心时提供“安装核心”按钮，直接跳转到版本管理；加载时卡片不再跳动。
- OAuth 登录按钮在检测浏览器期间显示加载动画和提示。
- Codex 子代理设置对话框新增加载状态和带“重试”的加载失败提示，长标题自动换行。
- 用量分析的成功率环形图说明文字不再与数值重叠，时间轴标签不再挤在一起，请求明细的范围说明更准确。
- 新手模式中选中的来源卡片更加醒目。
- 插件和设置搜索框加宽；数据管理的大小输入框增加边框、焦点状态和示例占位文字，深色主题下也清晰可见。
