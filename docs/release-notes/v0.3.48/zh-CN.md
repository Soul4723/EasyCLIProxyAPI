## 修复

- 修复在高级功能中打开日志文件夹时出现堆栈溢出错误（`Maximum call stack size exceeded`）的问题。
- 针对 Linux 上鼠标悬停后部分内容白屏或透明的重绘问题，恢复主窗口的不透明模式，覆盖 AMD / KDE 和 NVIDIA / Hyprland 等反馈场景。Windows 和 macOS 的原生半透明主题支持不受影响。[#491](https://github.com/router-for-me/EasyCLIProxyAPI/issues/491)

## 优化

- 优化后台资源使用：后台启动、最小化或缩到托盘时，同步主界面与插件 WebView 的可见性，暂停界面轮询和倒计时；恢复窗口后自动刷新最新数据。代理核心与用量采集继续运行。[#493](https://github.com/router-for-me/EasyCLIProxyAPI/issues/493)
- 用量页改为合并事件刷新，兜底轮询由每秒一次调整为每 10 秒一次；窗口隐藏时停止向界面发送用量更新事件，减少后台查询与渲染开销。
- 恢复浏览器默认后台节流策略。界面刷新根据原生窗口是否显示及是否最小化判断，不因单纯失去焦点而暂停。
- 将 Tauri 升级至 2.12.4 稳定版，并同步更新相关运行时与构建依赖。

## 部分历史更新

### 新增

- Codex「配置管理」新增**自动审批模型**设置，可选择 Codex 默认或指定模型；保存后同步到模型目录，新发现的模型自动继承设置。所选模型需能通过当前代理调用。
- Codex 新增**远程压缩（实验性）**开关，默认关闭，可在上游支持时启用服务端上下文压缩。
- Codex 支持切换为 `openai` 提供商标识，仍通过 CPA 代理；切换时可选择备份并同步本机历史会话。

### 优化

- 额度卡片支持按模型分组展示不同时间窗口的额度，增加重置倒计时，调整套餐信息和刷新按钮布局。
- 应用重启后可恢复上次的窗口位置。
- 插件安装过程中支持通过取消、关闭按钮或 Esc 中止安装请求。

### 修复

- 修复用量费用计算可能优先使用手动价格的问题，现在优先匹配实际原始模型的自动价格，再使用后备价格。
- 修复启用费用列后，推理 Token 数量被挤压、无法完整显示的问题。
- 修复配置页面中输入框挤压设置名称和说明文字的问题。
- 修复 macOS 下 DeepSeek Harness 桌面应用及其内置 CLI 的识别问题。

### 使用提示

- 修改 Codex 设置后，请重启对应的 CLI 服务或桌面应用。远程压缩开关会改变提供商名称；若历史会话不再显示，可前往「会话管理」重新同步。
