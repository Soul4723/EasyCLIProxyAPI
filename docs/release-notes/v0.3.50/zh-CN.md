## 新增

- 凭证详情支持手动刷新 OAuth 凭证；新增批量管理入口，可选择当前筛选结果，批量刷新、启用、停用或删除凭证，并查看逐项处理结果。
- 支持刷新服务器上所有符合条件的凭证，不限于当前筛选结果。
- 凭证设置新增折叠的「请求策略」，支持为单个凭证配置重试次数和错误处理规则，或恢复继承全局设置。
- xAI 凭证支持切换官方 API 与 Grok CLI chat-proxy 模式。

## 优化

- 凭证列表增加「存在问题」筛选，搜索支持匹配备注和模型前缀。
- 凭证管理页与额度查询页统一识别插件配额能力，支持展示额度窗口、重置时间、套餐及余额等插件返回的摘要。
- 插件额度支持单独刷新和全部刷新；兼容旧内核未返回插件 ID 的情况，并合并并发插件查询。内置供应商继续优先使用原有额度查询逻辑。
- 保留现有凭证列表布局，新操作放在详情、设置和批量管理弹窗中。

## 修复

- 修复独立额度查询页遗漏插件凭证的问题。由插件提供配额能力的 Gemini 等凭证现在可以显示并查询额度。
- 凭证启停请求携带凭证索引，避免同名凭证定位不明确。
- 延长凭证刷新请求的等待时间，减少批量刷新尚未完成就超时的情况。

## 使用说明

- 「刷新凭证」用于更新认证凭证，不会重置额度。刷新全部凭证可能需要几分钟。
- 普通 Gemini OAuth 登录不代表支持额度查询；是否可查取决于后端及插件提供的配额能力。
