## 新機能

- 認証情報の詳細から OAuth 認証情報を手動更新できるようになりました。一括管理ダイアログでは、絞り込み結果から対象を選び、更新、有効化、無効化、削除を実行して個別の処理結果を確認できます。
- 現在の絞り込みに関係なく、サーバー上の対象認証情報をすべて更新できるようになりました。
- 認証情報の設定に、折りたたみ式の「リクエストポリシー」を追加しました。認証情報ごとの再試行回数やエラー処理ルールを設定し、全体設定の継承に戻すこともできます。
- xAI 認証情報で、公式 API と Grok CLI chat-proxy を切り替えられるようになりました。

## 改善

- 認証情報一覧に問題のある項目の絞り込みを追加し、メモとモデル接頭辞も検索対象にしました。
- 認証情報管理と割当量ページでプラグインの割当量対応判定を統一しました。利用枠、リセット時刻、プラン、残高など、プラグインが返す概要を表示できます。
- プラグイン割当量の個別更新と一括更新に対応しました。プラグイン ID を返さない旧コアにも対応し、同時実行されるプラグイン一覧の取得を共有します。組み込みプロバイダーでは従来の割当量取得を優先します。
- 既存の認証情報一覧のレイアウトを維持し、新しい操作を詳細、設定、一括管理ダイアログに配置しました。

## 修正

- 専用の割当量ページからプラグイン認証情報が除外される問題を修正しました。プラグインが割当量に対応する Gemini などの認証情報も表示・取得できます。
- 有効化・無効化リクエストに認証情報のインデックスを含め、同じファイル名の認証情報を区別できるようにしました。
- 認証情報更新リクエストの待機時間を延長し、一括更新の完了前にタイムアウトする状況を減らしました。

## 使用上の注意

- 認証情報の更新は認証データを更新する操作で、割当量をリセットしません。すべての認証情報の更新には数分かかる場合があります。
- 通常の Gemini OAuth ログインだけでは割当量の取得はできません。バックエンドとプラグインによる割当量対応が必要です。
