## 新增

- 憑證詳情支援手動重新整理 OAuth 憑證；新增批次管理入口，可選取目前篩選結果，批次重新整理、啟用、停用或刪除憑證，並查看逐項處理結果。
- 支援重新整理伺服器上所有符合條件的憑證，不限於目前篩選結果。
- 憑證設定新增可摺疊的「請求策略」，支援為單一憑證設定重試次數及錯誤處理規則，或恢復繼承全域設定。
- xAI 憑證支援切換官方 API 與 Grok CLI chat-proxy 模式。

## 最佳化

- 憑證清單增加「存在問題」篩選，搜尋支援比對備註及模型前綴。
- 憑證管理頁與額度查詢頁統一識別外掛配額能力，支援顯示額度視窗、重置時間、方案及餘額等外掛傳回的摘要。
- 外掛額度支援個別及全部重新整理；相容舊版核心未傳回外掛 ID 的情況，並合併並行外掛查詢。內建供應商繼續優先使用原有額度查詢邏輯。
- 保留現有憑證清單配置，新操作放在詳情、設定及批次管理對話框中。

## 修復

- 修復獨立額度查詢頁遺漏外掛憑證的問題。由外掛提供配額能力的 Gemini 等憑證現在可以顯示並查詢額度。
- 憑證啟停請求攜帶憑證索引，避免同名憑證定位不明確。
- 延長憑證重新整理請求的等待時間，減少批次重新整理尚未完成就逾時的情況。

## 使用說明

- 「重新整理憑證」用於更新認證憑證，不會重置額度。重新整理全部憑證可能需要幾分鐘。
- 一般 Gemini OAuth 登入不代表支援額度查詢；是否可查取決於後端及外掛提供的配額能力。
