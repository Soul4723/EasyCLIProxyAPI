## 新增

- 为 DeepSeek Harness 桌面版新增“重启 App”按钮，交互与 Codex App 一致，支持自动识别安装位置和手动指定可执行文件路径。

## 修复

- 修复通过本软件配置 ZCode 后无法选择思考级别的问题。现在会根据模型支持的档位生成配置，支持自定义模型名，并保留已有的手动设置。
- 更新后，请重新应用 ZCode 配置，完全退出并重启 ZCode，再创建新会话以使用更新后的思考级别选项。
