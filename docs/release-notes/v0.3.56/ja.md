## 新機能

- DeepSeek Harness のデスクトップ版に、Codex App と同様の「アプリを再起動」ボタンを追加しました。インストール先の自動検出と、実行ファイルのパスの手動指定に対応します。
- 「アプリを再起動」と既存の「Web を再起動」は、デスクトップアプリと Web サービスをそれぞれ個別に操作します。デスクトップ版が検出されない場合、「アプリを再起動」ボタンは無効になります。

## 修正

- 本アプリで設定した ZCode で思考レベルを選択できない問題を修正しました。モデルが対応するレベルに基づいて設定を生成し、カスタムモデル名にも対応します。既存の手動設定は保持されます。
- 更新後は ZCode の設定を再適用し、ZCode を完全に終了して再起動してから、新しいセッションで更新された思考レベルの選択肢をご利用ください。
