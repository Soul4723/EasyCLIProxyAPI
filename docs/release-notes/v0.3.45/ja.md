## 新機能

- Codex の設定管理に**自動承認モデル**を追加しました。Codex デフォルトまたは特定のモデルを選択して管理対象のモデルカタログに保存でき、新しく検出されたモデルにも設定が引き継がれます。選択したモデルは現在のプロキシ経由で呼び出せる必要があります。
- Codex に**リモート圧縮（実験的）**の切り替えを追加しました。既定ではオフで、上流サービスが対応している場合にサーバー側でコンテキストを圧縮できます。
- CPA プロキシ経由の接続を維持したまま、Codex のプロバイダー識別子を `openai` に切り替えられるようになりました。切り替え時にローカルのセッション履歴をバックアップして同期することもできます。

## 改善

- クォータカードでモデルごとに利用枠をグループ表示し、リセットまでの残り時間を表示するようになりました。プラン情報と更新ボタンの配置も調整しました。
- アプリの再起動時に前回のウィンドウ位置を復元するようになりました。
- プラグインのインストール中でも、キャンセル、閉じるボタン、または Esc でインストール要求を中止できるようになりました。

## 修正

- 利用料金の計算で手動設定の価格が意図せず優先される問題を修正しました。実際の元モデルの自動価格を優先し、見つからない場合に代替価格を使用します。
- 料金列を有効にすると推論トークン数の表示が圧迫され、見切れる問題を修正しました。
- 設定画面で入力欄が設定名や説明文を圧迫する問題を修正しました。
- macOS で DeepSeek Harness のデスクトップアプリと同梱 CLI を検出できない問題を修正しました。

## ご利用上の注意

- Codex の設定を変更した後は、該当する CLI サービスまたはデスクトップアプリを再起動してください。リモート圧縮の切り替えによりプロバイダー名が変更されます。過去のセッションが表示されなくなった場合は、セッション管理から再同期してください。

## 修正

- Windows で VSCode Copilot のインストール状況やバージョンを確認する際に、VS Code が意図せず起動して複数のウィンドウを復元し、確認処理のタイムアウト後にそれらのプロセスが強制終了されることがある問題を修正しました。繰り返しの確認によってエディターの起動と終了が続く現象を防ぎます。
