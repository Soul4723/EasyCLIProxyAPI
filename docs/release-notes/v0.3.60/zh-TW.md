## 新增

- 新增「渐离の梦境」主題，採用紫粉漸層與半透明毛玻璃面板，提供「星穹暮色」「櫻花晴空」和純色漸層背景，並支援上傳、清除自訂桌布。
- 主題選擇器新增自訂主題製作指南，可一鍵複製包含製作規則、完整範例和 JSON Schema 的提示詞，交給 AI 按喜好或參考圖製作主題。
- Codex 工作階段刪除對話框新增「刪除前建立備份」選項，預設開啟；取消勾選後可直接刪除，並顯示無法復原的提示。

- 調整桌面介面的卡片、邊框、陰影和導覽樣式；API 接入中的空分類淡化顯示，OAuth 帳號標籤增加狀態圓點，用量統計卡片的資訊層次更清晰。

## 修復
