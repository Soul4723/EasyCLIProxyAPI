## 追加

- 紫とピンクのグラデーションと半透明のすりガラス風パネルを使った「渐离の梦境」テーマを追加しました。星空・桜空のプリセットやグラデーション背景を選べるほか、独自の壁紙のアップロードと削除に対応しています。
- テーマ選択画面にカスタムテーマの作成ガイドを追加しました。ルール、完全なサンプル、JSON Schema を含むプロンプトをコピーし、好みや参考画像に合わせたテーマの作成を AI に依頼できます。
- Codex セッションの削除ダイアログに、初期状態で有効な「削除前にバックアップを作成」オプションを追加しました。無効にすると直接削除でき、復元できないことを示す注意文が表示されます。

## 改善

- デスクトップ画面のカード、枠線、影、ナビゲーションを調整しました。API 接続の空のカテゴリを控えめに表示し、OAuth アカウントのラベルに状態を示すドットを追加しました。使用量の統計カードも読み取りやすくなりました。
- Kimi の月間総クォータ、月間コーディングクォータとそれぞれのリセット時刻を表示するようにしました。取得できる場合はプラン名も表示します。
- クォータカード下部のリセット時刻と更新ボタンの位置を揃え、レイアウトをコンパクトにしました。
- コアバージョンを v8.0.48 に更新しました。

## 修正

- Kimi のクォータ取得先ドメインが正しく判定されない問題を修正しました。認証情報に応じて kimi.com または kimi.ai を選択し、管理センターと同じ動作になります。
- ページを切り替えた際に前のページのスクロール位置が引き継がれる問題を修正しました。新しいページは先頭から表示されます。
- 壁紙設定の保存に失敗しても表示が切り替わる問題を修正しました。画像の読み込みやローカルストレージへの保存に失敗した場合は、エラーを表示して以前の表示設定を維持します。
- Codex セッションの一括削除時に、長いタイトルや大量の内容で確認ダイアログがウィンドウからはみ出す問題を修正しました。内容をスクロールでき、操作ボタンは表示されたままになります。
