## 新增

- 新增“渐离の梦境”主题，采用紫粉渐变与半透明毛玻璃面板，提供“星穹暮色”“樱花晴空”和纯色渐变背景，并支持上传、清除自定义壁纸。
- 主题选择器新增自定义主题制作指南，可一键复制包含制作规则、完整示例和 JSON Schema 的提示词，交给 AI 按喜好或参考图制作主题。
- Codex 会话删除对话框新增“删除前创建备份”选项，默认开启；取消勾选后可直接删除，并显示无法恢复的提示。

## 优化

- 调整桌面界面的卡片、边框、阴影和导航样式；API 接入中的空分类弱化显示，OAuth 账号标签增加状态圆点，用量统计卡片的信息层次更清晰。
- Kimi 额度支持显示月总额度、月编程额度及对应重置时间，并在可获取时显示套餐名称。
- 额度卡片底部的重置时间与刷新按钮对齐，布局更加紧凑。
- 核心版本更新至 v8.0.48。

## 修复

- 修复 Kimi 凭证额度查询域名判断不准确的问题，依据凭证信息选择 kimi.com 或 kimi.ai，与管理中心保持一致。
- 修复切换页面后沿用上一页滚动位置的问题，新页面会从顶部显示。
- 修复壁纸设置保存失败时仍切换显示的问题；图片加载或本地存储失败时显示错误提示，并保留原有显示设置。
- 修复批量删除 Codex 会话时，长标题或过多内容导致确认对话框超出窗口的问题，内容区域可滚动，操作按钮保持可见。
