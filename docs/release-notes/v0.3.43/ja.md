## 新機能

- Codex モデルエディターに「Tool Search を許可」スイッチを追加し、モデルごとに設定できるようになりました。設定はモデルカタログの更新、同期、再起動後も保持されます。この機能にはモデルと上流プロバイダー双方の対応が必要です。互換性がない場合は無効にしてください。

## 修正

- プロバイダー名や複数階層のパスを接頭辞に持つモデル ID が、公式モデルテンプレートと正しく照合されない問題を修正しました。完全なルーティング ID を維持しながら、対応するモデルの能力を継承します。
- ZCode のインストール状況やバージョンを確認する際に、アプリケーションが意図せず起動することがある問題を修正しました。
