## 修正

- Pi の設定画面とプラグインのモデル一覧を統一しました。非表示モデルを除外し、既定モデルも同じ一覧で検証することで、Pi で利用できないモデルの選択を防ぎます。[#527](https://github.com/router-for-me/EasyCLIProxyAPI/pull/527)
- Pi プラグインのインストール・更新、または設定の適用時に古いモデルキャッシュを削除し、Pi の次回起動時に最新の一覧を取得するようにしました。削除できない場合は、以降の設定書き込みを中止してエラーを表示します。
- Pi モデルの初期化で思考レベルのフィールドが欠けていたために発生したビルドエラーを修正しました。既存の ZCode の思考レベル対応は維持されます。

## 改善

- CPA 経由で DeepSeek Harness に接続するモデルは、既定でテキストと画像の入力を有効にします。カスタムモデル名や画像対応情報を返さないモデルも対象です。設定の再適用で以前の自動生成設定も更新され、手動の上書き設定は保持されます。

## ご利用上の注意

- 更新後は DeepSeek Harness の設定を再適用し、対応する App または Web サービスを再起動してください。Pi の設定変更後も、最新のモデル一覧を読み込むために Pi を再起動してください。
- 画像入力の設定はクライアントからの画像送信を許可します。実際の画像認識への対応は、選択したモデルと上流サービスに依存します。

## 過去の主な更新

### 新機能

- DeepSeek Harness のデスクトップ版に、Codex App と同様の「アプリを再起動」ボタンを追加しました。インストール先の自動検出と、実行ファイルのパスの手動指定に対応します。
- 「アプリを再起動」と既存の「Web を再起動」は、デスクトップアプリと Web サービスをそれぞれ個別に操作します。デスクトップ版が検出されない場合、「アプリを再起動」ボタンは無効になります。

### 修正

- 本アプリで設定した ZCode で思考レベルを選択できない問題を修正しました。モデルが対応するレベルに基づいて設定を生成し、カスタムモデル名にも対応します。既存の手動設定は保持されます。
- 更新後は ZCode の設定を再適用し、ZCode を完全に終了して再起動してから、新しいセッションで更新された思考レベルの選択肢をご利用ください。
