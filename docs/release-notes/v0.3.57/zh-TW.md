## 修復

- 修復 Pi 設定頁面與 Pi 外掛的模型清單不一致的問題，過濾隱藏模型，並依同一清單驗證預設模型，避免選到 Pi 中無法使用的模型。[#527](https://github.com/router-for-me/EasyCLIProxyAPI/pull/527)
- 安裝、更新 Pi 外掛或套用設定時清除舊模型快取，讓 Pi 下次啟動取得最新清單；若無法清除快取，則停止後續設定寫入並提示錯誤。
- 修復 Pi 模型設定合併後缺少推理級別欄位造成的編譯失敗，保留既有的 ZCode 思考級別支援。

## 改善

- 透過 CPA 接入 DeepSeek Harness 的模型預設啟用文字與圖片輸入，包含自訂模型名稱及未回傳視覺能力資訊的模型。重新套用設定時會更新舊版自動產生的設定，既有的手動覆寫設定仍會保留。

## 使用提示

- 更新後請重新套用 DeepSeek Harness 設定，並重新啟動對應的 App 或 Web 服務。Pi 設定變更後也需重新啟動 Pi，才能載入最新模型清單。
- 圖片輸入設定允許用戶端傳送圖片，實際辨識能力仍取決於所選模型與上游服務。
