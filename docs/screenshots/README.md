# Screenshots

The images here are renders of the **real debug app** (Tauri/WebKitGTK with the production frontend
embedded), not of the browser mock. They are 1280×800 captures of the app's own window on a private
virtual display, taken in Local mode against a fresh test core with no accounts, credentials or usage
history, and then colour-reduced to keep them small. See [Observe the real debug app](../dev-observe.md)
for how those runs are made.

Before replacing an image, check it for hostnames, user paths, keys and real accounts; the harness
captures whatever the test sandbox shows. Do not use Settings → Access keys captures: the page lists key
values.
